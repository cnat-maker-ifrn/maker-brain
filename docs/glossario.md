# Glossário

|Termo|Significado|
|:--|:--|
|Bolsista|Aluno que trabalha no laboratório CNAT Maker|
|Solicitante|Pessoa que agenda uma visita ou solicita um serviço|
|Agendamento|Reservar uma data e horário para uma visita|
|Visita|Visita ao laboratório com o intuito de conhecê-lo|
|Serviço|Serviços prestados pelo laboratório como impressão 3D, corte a laser e estampagem|
