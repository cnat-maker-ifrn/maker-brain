# MakerBrain
MakerBrain is an open-source, full-stack platform designed to optimize the management of the CNAT Maker Lab at IFRN.

Built with scalability in mind, the system is designed to be easily replicated and adapted by other maker spaces and laboratories. Currently, the platform features secure authentication, user management, and an integrated scheduling system.
